# Painel de Treinos

Tela instalável do Painel de Treinos do Box Lanziere Lelis, publicada pelo GitHub Pages.

Este repositório é público e guarda só a tela: não há treinos, códigos de acesso nem chaves aqui.
Os dados ficam em um Google Doc e só chegam a quem tem um código pessoal válido, conferido no servidor.

O `index.html` é gerado: a fonte fica no projeto do painel, fora deste repositório.
